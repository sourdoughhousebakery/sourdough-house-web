## Verification

- Shopify returned the chosen color as the first variant and the matching front mockup as the featured media for all 16 products.
- The draft Apparel collection loaded all 16 matching front card images.
- Each product's no-variant storefront URL selected the intended color and first available size, and its main gallery image used that color's front mockup.
- For two-sided products, the matching back image was kept immediately after the featured front. Sleeve views were likewise kept beside the matching front where applicable.
- Artwork files, print placement, prices, inventory, and Printful fulfillment mappings were unchanged.

The draft theme remains unpublished. Product variant and media ordering are Shopify product data and therefore apply to every theme that uses Shopify's default product ordering.
